DSH 规范与先例实施对照

  • 表单与草稿状态机：遵循 SettingsForm 原语规范，由控制器自持草稿，不使用文本暂存，以整段 set path op 写入数组与对象配置（依据 ui-settings-subagent/subagent-model-selection-card-controller.ts）。
  • 视觉 Token 全面合规：完全采用 DSH 官方 ui-theme/design-platform.css 的变量（--dsw-alias-bg-*、--dsw-alias-border-*、--dsw-alias-label-*），拒绝硬编码色值，并完美支持深浅主题双向自适应。
  • 模型候选选择体验：摒弃原设计中两个生硬文本框拼凑的做法，采用 ModelListEditor 范式结合模型目录（ctx.remote.session.modelCatalog()）弹窗多选注入，手输仅作为离线兜底。
  • 降级链可视化表达：将冰冷的列表升级为具有流向指示的 Pipeline 链路卡片，显著降低配置心智负担，与产品“透明故障转移”核心价值高度呼应。
